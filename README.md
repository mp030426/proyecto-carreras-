# Proyecto Carreras de Perros 🐶🏁

Sistema CRUD desarrollado en Python con Tkinter y MongoDB.  
Este proyecto fue creado durante mi primer año de Ingeniería Informática e incluye lógica de carreras, relación entre perros y eventos, y análisis de rendimiento por temporada.

## 🚀 Tecnologías Utilizadas
- Python
- Tkinter
- MongoDB
- Pymongo
- Pillow (para imágenes)

## 🎯 Funcionalidades Principales
- CRUD completo de perros
- CRUD de carreras
- Relación perro ↔ carrera
- Filtro de perros por tiempo
- Determinar el mejor perro por temporada
- Interfaz gráfica básica en Tkinter
- Conexión a MongoDB
